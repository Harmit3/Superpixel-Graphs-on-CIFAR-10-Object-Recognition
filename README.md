# GNN-Based Object Recognition via Superpixel Graphs on CIFAR-10

## Project Overview

This project studies whether graph neural networks can classify images after each image is converted into a graph of superpixels. Instead of treating an image only as a fixed grid of pixels, the pipeline first groups nearby visually similar pixels into SLIC superpixels. Each superpixel becomes a graph node, and neighbouring superpixels are connected by graph edges. The final graph is then classified using three GNN architectures:

1. **Baseline GNN using GraphSAGE**
2. **Graph Convolutional Network (GCN)**
3. **Graph Attention Network (GAT)**

The experiment uses the CIFAR-10 dataset and compares the models on a smaller controlled subset because graph conversion and GNN training are slower than standard CNN training.

## Research Question

Can superpixel graph representations support object recognition on CIFAR-10, and which GNN architecture performs best under this representation?

## Dataset

- Dataset: CIFAR-10
- Classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck
- Original image size: 32 x 32 RGB
- Preprocessing resize: 64 x 64 RGB
- Training subset used: 2,000 images
- Test subset used: 500 images

## Method Summary

### 1. Image Preprocessing

Each CIFAR-10 image is resized to 64 x 64 pixels. This gives the SLIC algorithm more spatial detail than the original 32 x 32 version.

### 2. Superpixel Segmentation

The SLIC algorithm divides the image into approximately 75 superpixels using a compactness value of 10. The actual number of regions can vary slightly depending on the image.

### 3. Graph Construction

Each image is converted into a graph:

- Node = one superpixel
- Node features = mean RGB colour + normalized x/y centroid position
- Edge = two superpixels share a boundary
- Edges are made bidirectional for message passing

Each node therefore has a 5-dimensional feature vector:

```text
[R_mean, G_mean, B_mean, x_position, y_position]
```

### 4. Model Training

All models use a similar high-level design:

- Three message-passing layers
- ReLU activations
- Dropout regularization
- Global mean pooling
- Two-layer MLP classifier
- Cross-entropy loss
- Adam optimizer
- 30 training epochs

## Main Results

| Model | Test Accuracy | Train Accuracy | Test Loss | Approx. Training Time |
|---|---:|---:|---:|---:|
| Baseline GNN / GraphSAGE | 20.60% | 22.30% | 2.083 | ~420 s |
| GCN | 29.40% | 34.10% | 1.882 | ~390 s |
| GAT | 25.20% | 26.50% | 2.043 | ~450 s |

The GCN model performed best. Its normalized aggregation method appears better suited to the superpixel graph structure than simple mean aggregation or attention-based aggregation in this small-data setting.

## Key Findings

- Superpixel graphs can represent images in a compact graph format.
- GCN achieved the best result with 29.40% test accuracy.
- GAT performed better than the baseline but did not beat GCN.
- Classes with more distinctive colour and background patterns, such as ship and horse, were easier to classify.
- Visually similar animal categories, such as cat, dog, and bird, were harder because simple mean-colour superpixel features lose fine texture information.

## Limitations

- Only 2,000 training images and 500 test images were used.
- Node features are limited to mean RGB colour and centroid position.
- No texture, depth, edge strength, or semantic features were included.
- CIFAR-10 images are low-resolution, which limits the quality of superpixel boundaries.
- The models were compared under one main superpixel configuration.

## Future Work

Possible improvements include:

- Use the full CIFAR-10 training set.
- Add texture features such as local binary patterns or Gabor filters.
- Add edge features such as boundary strength and distance between centroids.
- Test different numbers of superpixels.
- Compare with CNN and Vision Transformer baselines.
- Apply graph pooling methods such as DiffPool or TopKPooling.
- Integrate the model into a robotic perception or visual-language-action pipeline.
